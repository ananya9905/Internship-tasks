# Day 2 - Text Analyzer

## What the program does

This Python program analyzes a piece of text entered by the user.

It calculates and displays:

* Total word count
* Character frequency
* Longest word
* Average word length

The program uses separate functions for each operation and combines the results in the `main()` function.

## How to Run

Open the `Day-2` folder in the terminal and run the Python file:

```bash
python Text-analysis-tool.py
```

## Sample Run

```text
Enter the text: Python is easy to learn
1. Word Count: 5
2. Character Frequency: {'P': 1, 'y': 1, 't': 2, 'h': 1, 'o': 2, 'n': 2, 'i': 1, 's': 1, 'e': 2, 'a': 1, 'l': 1, 'r': 1}
3. Longest Word: Python
4. Average Word Length: 3.8
```
